1. SETUP                                              *claude-complete-setup*

Requires Neovim 0.10+, Node.js 20+ and github/copilot.vim. Do not lazy-load
copilot.vim or this plugin on an event.

Run once and paste your Anthropic API key (https://console.anthropic.com): >
    :ClaudeComplete setup
<
The key is saved to `stdpath('data')/claude-complete/api_key` (mode 600).
$ANTHROPIC_API_KEY, when set, takes precedence. `:Copilot setup` is not needed.

Completion keys, ghost text and the panel are copilot.vim's: |copilot-maps|.

==============================================================================
2. COMMANDS                                        *claude-complete-commands*

                                                       *:ClaudeComplete*
:ClaudeComplete setup         Save the Anthropic API key.
:ClaudeComplete backend {name}
                              Use `claude` or `copilot` (GitHub's own server,
                              needs a Copilot subscription and |:Copilot| setup
                              once). Restarts the server; remembered across
                              sessions.
:ClaudeComplete toggle        Switch to the other backend.
:ClaudeComplete model [{id}]  Without {id}, list every model the API key can
                              use (from the Models API) and pick one. Takes
                              effect without a restart; remembered across
                              sessions.
:ClaudeComplete info          Show backend, key source and paths.
:ClaudeComplete logout        Delete the saved key.

Useful copilot.vim commands with the claude backend:
  :Copilot status   `Ready`, or the problem (missing key, no credit, ...)
  :Copilot log      latency per request and errors

Health check: `:checkhealth claude_complete`

==============================================================================
3. CONFIGURATION                                     *claude-complete-config*

Optional: >lua
    require('claude_complete').setup({
      default_backend = 'claude',
      server = {
        model = 'claude-haiku-5-5',
        debounceMs = 100,
        maxLines = 8,
        maxTokens = 256,
        linesBefore = 200,
        linesAfter = 50,
        alternatives = 2,
      },
    })
<
`g:copilot_node_command` selects the Node.js binary for the server too.

==============================================================================
4. PRIVACY                                          *claude-complete-privacy*

Each suggestion sends the text around the cursor (default 200 lines above,
50 below) to the Anthropic API. Disable it where needed: >vim
    let g:copilot_filetypes = {'*': v:true, 'markdown': v:false}
    autocmd BufReadPre *.env,*.pem,*.key let b:copilot_enabled = v:false
<
==============================================================================
5. TROUBLESHOOTING                          *claude-complete-troubleshooting*

No suggestions          `:Copilot status`, then `:checkhealth claude_complete`
No Anthropic API key    `:ClaudeComplete setup`
Authentication failed   The key is wrong or revoked; run setup again.
credit balance too low  Buy API credit in the Anthropic console.
Odd suggestions         Start with `CLAUDE_COMPLETE_DUMP=/tmp/dump.txt nvim`
                        to log every prompt and raw reply.
